# 翻译风格指南（mathtranslations.org 规范 + 本书专用约定）

本指南依据 mathtranslations.org《制作规范》制定。所有译者必须逐条遵守。

## 一、忠实性与流畅性

1. **忠实第一**：只翻译原文内容，不添加原文没有的解释、证明、例子或评论，不删减任何句子。数学含义（量词、逻辑关系、假设、否定、公式意义）绝对不可改变。
2. **通顺自然**：在数学含义严格不变的前提下，译出流畅、地道的中文科技书语感。避免欧化长句、逐词硬译；长句可按中文习惯断句，但不可合并/拆散句子的信息内容。语气词、口语色彩（原文是轻松的科普口吻）要保留。
3. **一一对应**：原文的每一段 → 译文一段；原文的脚注 → 译文脚注（位置不变）；原文列表项 → 列表项。不要合并或新增段落。
4. **每句都译**：包括斜体强调、括号内插语、例子的每一问每一答。

## 二、术语规范

1. **一个概念一个译名**（见 glossary.md）。术语表中的译名必须逐字采用，不得自创。
2. 术语**首次正式出现**时用模式：`\emph{中文术语}（english term）`，例如 `\emph{感知机}（perceptron）`。之后再出现直接用中文术语，不再附英文。如果是小节标题级别的正式定义（如"Sigmoid 神经元"一节），正文首次给出定义处加 `\emph{}（英文）`。
3. glossary 未收录的新术语：自行给出中文译名（优先用社区通用译法），首次出现同样加 `\emph{}（english）`，并在译完的文件末尾用注释 `% NEWTERM: 中文 = english` 列出（便于汇总进术语索引）。
4. 人名保留英文原文（Nielsen、Rosenblatt、McCulloch、Pitts、LeCun、Hinton……），不音译。著名机构可意译（University of Montreal → 蒙特利尔大学）。
5. MNIST、Python、Numpy、GitHub、AWS 等专有名词保留英文。
6. 数学符号、公式、变量一律原样保留，**绝不翻译数学环境内的任何内容**（$...$ 与 equation/align 环境内的文字）。`\mbox{output}` 这类数学环境里的英文词保留原样。

## 三、标点与数字

1. 中文文本用中文标点：，、；：？！""''（）；**但句号一律用半角英文 "."**（mathtranslations.org 规范），即句子结尾用 "." 而不是"。"。
2. 破折号用 "——"。原文的 " - "（两端空格的连字符）若是插入语，译为 "——"；若是列表/范围，按中文习惯处理。
3. 引号用中文弯引号""''（Unicode 直排入文）。绝不用直引号 "。
4. 数字与单位用半角：50,000、0.99、28×28。百分比 "98.42%" 保持半角。
5. 括号：中文语境用全角（），数学/代码/英文短语紧贴时可用半角。术语注释统一用全角：`\emph{感知机}（perceptron）`。

## 四、LaTeX 结构（必须原样保留）

1. 以下内容**逐字保留，一字不改**：
   - 所有数学：`$...$`、`\begin{equation}...\end{equation}`、`\begin{align}...\end{align}`（含 `\tag{N}`、`\nonumber`、`\label`）
   - 所有 `\includegraphics[...]{...}` 及其外层的 `\begin{center}...\end{center}`
   - `%%CODEBLOCK_0%%` 之类的代码占位符行（保持原行原位）
   - `\inlineImg{...}`、`\tag{...}`
2. `\begin{exerciseBox}{XXX}` 的标题参数 XXX 必须按下表翻译（内容正常翻译）：
   - `Exercise` → `练习`；`Exercises` → `练习`；`Problem` → `习题`；`Problems` → `习题`
3. `\sectionTitle{EN}{EN}` / `\subsectionTitle{EN}{EN}`：两个参数都替换为标题译表（见 glossary.md 第二节）中的中文标题，两个参数内容相同。**标题必须逐字采用译表，不得改写。**
4. `\footnote{...}`：内容翻译，命令结构保留。
5. 列表环境 itemize/enumerate 原样保留，逐项翻译。
6. `\movieNote{...}` 的参数是文件名，**保留原样**；其盒内文字由模板生成（无需翻译参数）。
7. 不要改动任何 LaTeX 命令拼写；不确定的标记宁可原样保留。

## 五、语言风格细节

1. "network" 译"网络"；"neuron" 译"神经元"；"we" 译"我们"；"you" 译"你"（本书对话式口吻，用"你"不用"您"）。
2. 原文括号内举例 "(say)" 译"比如说"；"I've" 等第一人称保留"我"。
3. "It turns out that..." 不要译成"事实证明"，用自然表达如"结果发现/事实上"。
4. 代码相关的英文词（`network.SGD()`、`filename.py`、`epoch` 等作为代码对象时）保留英文。
5. 章节内引用如 "in Chapter 3" 译"在第 3 章中"；"Equation (10)" 译"式 (10)"；"the discussion above" 译"上面的讨论"。
6. 图的引用 "the figure below/above" 译"下图/上图"。
7. "problem" 在习题语境译"习题/问题"按术语表；"exercise" 译"练习"。
8. 输出中不得出现任何英文段落（术语、代码、人名、数学除外）。
